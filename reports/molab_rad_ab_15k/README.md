# Paired baseline / residual-adaptive sampling: 15k updates each

Two independent continuations start from the verified **287,400** final checkpoint (`72bbe88ddc539258b9bfb433709aa434776393bd5f7e163d90478cbf7fa0e6c2`), preserving Adam moments and RNG. Each targets **302,400**, with fixed LR **2e-5**, batch32,128 interior and48 outlet points. Baseline runs first, RAD next on the same GPU. This is a research comparison, not automatic acceptance or a promise of smaller FEM errors.

RAD retains64 randomly selected baseline points and samples64 without replacement from256 current candidates per geometry, proportional to `momentum_residual_norm / mean(norm) + 1`. Fresh candidate residuals use the current parameters and that batch's exact geometry and Re. This changes the unweighted training objective; raw training losses must not rank methods. Geometry, Re, original points and outlet draws use the same restored RNG stream in both branches. Additional RAD draws use an independent RNG; its state is saved in checkpoint metadata. Both branches cover the original training pool and Re10–100, and no development or FEM inputs enter gradients. The controller and optimizer equations are unchanged.

Fixed disjoint32+32 development cohorts are measured every2500 updates; identical saved20 Re30 FEM cases and8 Re10 pilot references are evaluated at start and every5000 updates. All individual errors, medians and maxima are retained, including regressions. These are limited development cases, not the full geometry/Re benchmark. Compare equal updates and actual wall time; candidate scoring adds cost.

Latest full state is saved every100 steps. Immutable full-state snapshots are retained after the first100 steps and at5000-step intervals. The first production-batch preflight compares the original update against the dynamic-LR core at2e-5 and checks256-point residual scores for finite valid shape before training. Frozen inputs, pool hash and normalization are verified. No training from the inaccessible later molab checkpoints is claimed.
