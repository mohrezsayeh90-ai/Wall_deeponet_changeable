# SOAP50000-update screening archive

[Plan, exact budget and evaluation criteria](../../../reports/molab_soap_sweep50k/README.md).

Five5000-update branches share a complete342400 SOAP checkpoint/RNG. A separate25000-update continuation of the constant1e-4 branch gives30000 total fixed-rate updates,50000 overall. Case directory names identify branches; their overlapping global step numbers are not a single sequential training history.

Immutable snapshots include all SOAP state and RNG; lengths/SHA256 are checked before upload. Raw `status.json` and `collection_status.json` are observations at their recorded collection time, not proof of current connectivity. Collection runs in Codex cloud and cannot guarantee further uploads if that environment stops. Preserve/download outputs before stopping Molab; cached plot images alone do not preserve weights.

After completion, `analysis_ready.json`, `comparison.json`, `common5k.csv`, `comparison.png`/`.pdf` and `analysis.md` contain the common-budget results and separate extension metrics. No200000-update job is automatically started.
